Replication of Diehl_Cook_2015

The original Paper: https://www.frontiersin.org/journals/computational-neuroscience/articles/10.3389/fncom.2015.00099/full

The open-source code: https://brian2.readthedocs.io/en/2.8.0.4/examples/frompapers.Diehl_Cook_2015.html

The data folder aggregates all experimental results and intermediate files produced by the train, observe, and test routines. To restore this directory within your environment, it may be beneficial to prepend the configuration code from Import_data_folder.ipynb to the beginning of Diehl_Cook_2015.ipynb. Please note that the author assumes no responsibility for any issues arising from the use of this code."
